How to setup replication in postgres
-------------------------------------
1. take the backup of primary (machine 1) from machine 2.
/usr/pgsql-18/bin/pg_basebackup -D /u01/pgsql/18 --checkpoint=fast -P -h 192.168.254.128

2. tell your postmaster that lab02 is a standby machine and not a standalone machine
touch standby.signal

3. get the archivelogs from lab01 and apply them continously in lab02
restore_command = 'scp 192.168.254.128:/u01/archivelogs/%f %p'

4. set primary_conninfo to make lab02 read primary wals.
primary_connfinfo="user=postgres password=postgres host=192.168.254.128
